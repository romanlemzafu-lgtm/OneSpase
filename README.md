# OneSpase v0.3.1

OneSpase — уютный мессенджер + социальная сеть в разработке.

## Что уже работает в прототипе

- локальный профиль;
- имя и `@username`;
- пользовательский статус;
- дата регистрации;
- локальная лента;
- создание постов;
- лайки;
- локальные комментарии;
- демо-чаты;
- отправка сообщений;
- сохранение данных после перезапуска;
- чёрно-белый фирменный стиль OneSpase;
- иконка приложения;
- автоматическая GitHub Actions сборка APK.

Пока всё хранится **локально на одном устройстве**. Серверная синхронизация будет следующим крупным этапом.

## Автоматическая сборка APK

После загрузки проекта в GitHub любой push в `main` запускает workflow **Build OneSpase APK**.

После успешной сборки APK находится:

`GitHub -> Actions -> Build OneSpase APK -> последний успешный запуск -> Artifacts -> OneSpase-v0.3.1-APK`

## APK через GitHub Releases

В проекте есть второй workflow. Если создать и отправить тег, например:

```bash
git tag v0.3.1
git push origin v0.3.1
```

GitHub автоматически соберёт `OneSpase-v0.3.1.apk` и прикрепит его к новому GitHub Release.
